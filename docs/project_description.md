# Опис інформаційної системи

## Призначення

Service Booking System призначена для онлайн-запису клієнтів на послуги, управління розкладом спеціалістів, підтвердження бронювань адміністратором та рекомендації оптимального часу запису.

## Ролі

1. Клієнт — створює запис, переглядає власні записи, скасовує запис.
2. Адміністратор / оператор — переглядає всі записи, підтверджує та скасовує їх, контролює каталог послуг і персоналу.
3. Спеціаліст — переглядає власний графік, позначає послугу як виконану.

## Об'єкти предметної області

- Користувач;
- Роль;
- Послуга;
- Спеціаліст;
- Запис / бронювання;
- Розклад;
- Статус запису;
- Сповіщення;
- ML-рекомендація.

## ML-компонент

ML-рекомендації не винесені в окремий розділ. Вони вбудовані у форму створення запису. Після вибору дати та спеціаліста система аналізує історію підтверджених записів і пропонує оптимальні вільні часові слоти.
