# Нотатки для лабораторної з тестування

Критичні компоненти для перевірки:

- авторизація та розмежування ролей;
- створення запису клієнтом;
- підтвердження запису адміністратором;
- перегляд власного графіка спеціалістом;
- скасування запису;
- збереження запису у SQLite;
- ML-рекомендація часу в формі створення запису;
- заборона вибору зайнятого слота.

Приклад дефекту:

ML-рекомендація пропонує зайнятий слот. Очікувано: рекомендації мають містити тільки вільні слоти.
